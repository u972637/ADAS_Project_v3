# 음향 테스트 데이터 시트

스피커 거리·각도·주파수별 음압(dB) 측정 결과를 기록하는 시트. 나중에
MATLAB에서 이 CSV를 읽어 그래프를 그릴 예정이다.

## 파일

- `with_reflector.csv` — 반사판 있는 버전
- `without_reflector.csv` — 반사판 없는 버전

## 열(column)

| 열 | 의미 |
| --- | --- |
| `distance_m` | 측정 거리(미터). 1,5,10,20,30,50(6개) — 측정 중 가장 안 바뀌는 값이라 맨 앞. |
| `angle_deg` | 스피커 조준 각도. 0/15/30/45/60/90/180도(7개). |
| `frequency_hz` | 테스트 주파수. 500~1500Hz 100Hz 간격(11개) + 2000/3000/4000Hz(3개) — 총 14개 — 측정 중 가장 자주 바뀌는 값이라 맨 뒤. |
| `dB` | 측정한 음압(dB). 1회만 측정 — 반복 평균 없음. |
| `deviation_dB` | 같은 조건에서 측정기가 보인 편차(흔들림 폭). |
| `baseline_dB` | 그 조건에서의 배경/기준 소음 레벨(ambient baseline, dB) — 스피커 신호와 별개로 측정한 "기본" 상태값. |

행 순서는 `distance_m` → `angle_deg` → `frequency_hz` 순으로 정렬돼 있다
(거리 고정 → 각도 고정 → 주파수만 빠르게 스윕하는 실제 측정 순서와 맞춤).
각 CSV는 6개 거리 × 7개 각도 × 14개 주파수 = 588행이다.
